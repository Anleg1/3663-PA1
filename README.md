# Sistema de Gestión de Inventario - Microempresa

## Descripción Breve
Este proyecto es un sistema por consola programada en Java, que va a ayudar a una microempresa a gestionar sus artículos. El sistema permite registrar productos, mostrar el inventario, realizar ventas con validación de stock y calcular los ingresos totales.

## Instrucciones de Ejecución:
1. Clonar o descargar este repositorio.
2. Abrir el proyecto con IntelliJ IDEA.
3. Dirigirse a la ruta: `src/main/java/com/lideratec/Main.java`.
4. Ejecutar el archivo `Main.java` dándole al botón con una flecha verde .
5. Interactuar con el menú escribiendo las opciones numéricas pudiendo colocar (1) para registrar un nuevo producto, (2) Para mostrar todos los productos, (3) para realizar una venta, (4) para ver el total ganado y por ultimo (5) para salir del sistema.
